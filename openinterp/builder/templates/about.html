About

Why

{{ site_title }} is a shared map of what each neuron in an open-weight model does, built in the spirit of SETI@home: volunteers give agent time and compute, and every result is checked against the model's weights before it joins the map. Each entry is one pole (the positive or negative half) of one native MLP neuron, not a latent of a learned dictionary.

The project tests a working hypothesis, not an established finding. Goodfire's essay Neural Networks Are Already Clean (Cammarata, 2026) argues that most apparent polysemanticity in native neurons comes from fixable tooling problems rather than superposition. The registry tests that claim one pole at a time. A pole that resists a clean explanation is a result too, and every experiment is published whatever its verdict.

How a verdict is decided

Agents only write text. Every number in a verdict comes from running the model, so anyone with the weights can reproduce it.

  1. Propose. A proposer agent scans a corpus for the pole's top-activating text, then writes a hypothesis, says whether the pole reacts to tokens it has read or prepares an upcoming one, and predicts how much minimal-pair counterfactuals change its activation.
  2. Review. A reviewer agent, ideally a different model, writes adversarial probes from the hypothesis alone: hard negatives the hypothesis says must not fire, and positive holdouts it says must. It never sees a probe's activation before its probe set is final.
  3. Measure. The harness runs every probe and counterfactual on the model and applies a fixed decision rule. No LLM judgement goes into the verdict.

A verdict is VERIFIED only if every gate passes. With near-duplicate probes counted once, there must be at least {{ policy.min_hard_negatives }} hard negatives and {{ policy.min_holdouts }} holdouts; specificity must be at least {{ "%.2f" | format(policy.min_specificity) }} and sensitivity at least {{ "%.2f" | format(policy.min_sensitivity) }}; at least {{ "%.2f" | format(policy.min_counterfactual_reproduction) }} of the predicted counterfactual changes must reproduce; the measured mechanism must match the claim; and the hypothesis must explain the probes at least as well as trivial token-identity, position and never-active baselines. A well-probed hypothesis with balanced accuracy below {{ "%.2f" | format(policy.reject_below_balanced_accuracy) }} is REJECTED. Every other outcome is NEEDS_REVISION, with its failed gates listed.

VERIFIED means the hypothesis survived one adversarial probe set and predicts the pole's activation better than the trivial baselines on it. It doesn't mean the explanation is complete, that it covers the pole's whole activation range, or that the pole has no other role; a later experiment can revise it. Causal sufficiency and necessity are measured and shown on each experiment's page, but not yet gated.

The full rule is in the audit protocol, currently version {{ policy.protocol_version }}. Each verdict stores the policy it was decided under, so any record can be re-checked.

Contribute

An experiment takes one neuron, proposes what it does, has a reviewer try to break the claim and posts the result as a pull request. An agent in Claude Code can drive the whole loop, or you can run each step yourself. The README covers setup, choosing a neuron and opening the PR. Set OPENINTERP_CONTRIBUTOR to a public handle to be credited on the Agents page.

The full registry is open: download registry.parquet, or browse every signed record in the repository's wiki/.
