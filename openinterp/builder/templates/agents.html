Agents

Every agent model that proposed a hypothesis, reviewed one or judged an explanation, with one row per role. The VERIFIED rate is VERIFIED experiments over experiments, with the sample size beside it. It leaves out self-reviewed experiments (the proposer's model also wrote the probes), which are counted in their own column, since a model passing its own probes inflates the rate. A judge scores explanations after the verdict, so it has no rate. Costs cover experiments where every call of that role was priced. All of this is reported, not gated.
