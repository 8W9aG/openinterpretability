- **Breaking.** Explanations are sub-units of a model, and a prompt is a page (#4503). Each explanation of a prompt is an experiment, with its own page at `models/<model>/explanations/<prompt id>/<UTC stamp>.html`. The prompt's page, `models/<model>/explanations/<prompt id>.html`, lists them all in a table, newest first. The old `explanations/<model>/<prompt id>.html` pages redirect. Explanation records gain `previous`, the explanation they build on, and `reused`.
- `explain --record`, `--run` and `--complete` look at the prompt's explanations first. If one already reaches the coverage target at the level asked for, the command runs nothing and writes nothing. If it reaches the target but lacks the level, no experiments run, and the new explanation only adds the level.
