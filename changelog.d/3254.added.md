- **A size budget for the repository, tracked in CI** (`scripts/repo_size.py`, `docs/analyses/repo-size.md`, #3254). CI reports the tracked size, the file count and the packed size of `.git`, and warns past `[tool.openinterp.size_budget]` (1,000 MB and 20,000 files). It never fails the job. `wiki/` grows by about 170 MB a week. Top examples and scored windows are 70% of each record. Where records live in the long term is still open.
