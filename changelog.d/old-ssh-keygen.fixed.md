- **An old `ssh-keygen` no longer looks like an expired signing key** ([openinterpretability/signing.py](../openinterpretability/signing.py)). OpenSSH 8.9 (Ubuntu 22.04) cannot read the allowed-signers times that end in "Z". So it ignored the signer line, and auto-signing deleted each new signature as "outside its window". Now the warning says that `ssh-keygen` is too old, and that a newer one must go first on `PATH`.
