- **Several agents can work issues and releases at once.** `scripts/issue_state.py --claim <number>` claims an issue with a branch that only one agent can create, and sets it In Progress. A second agent gets exit code 3 and takes the next issue. `--claim-release <tag>` claims the release, `--unclaim <number>` drops an issue's claims, and `--whoami` prints the agent's ID that comments carry. `next_issue.py` prints the claim command for each pick. The `next-issue`, `work-an-issue` and `release` skills claim before any work, and `docs/development.md` gives the rules for several agents (#6725).
