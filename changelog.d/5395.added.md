- **CI fails a PR that closes an issue that a paper's status line still names** (#5395). `scripts/papers.py check --closing` reads the PR's closing issues, and fails if a preprint's line names one. A nightly job runs `check --online`, which asks GitHub for every issue on every line and fails on a closed one. Both read the line with the site's own parser, so an issue in brackets is a citation, not work left. The `write-paper` and `work-an-issue` skills give the close-out step.
