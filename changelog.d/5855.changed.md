- Every line that a pull request changes must now be covered by a test, or marked `# pragma: no cover` with its reason (#5855). The threshold is set once, as `[tool.diff_cover] fail_under = 100` in `pyproject.toml`. `make coverage` and CI's diff-cover step both read it. The `test-new-paths` skill says when the pragma is allowed. New tests close the gaps in 217 modules, from those that missed one line to the largest CLI modules. Package coverage rises from 90.92% to 100%, and the floor from 90 to 100. Three unreachable guards are marked with their reasons, and one redundant check in `concept_map.py` is removed.
- The secret scan no longer takes the validity date of a test ssh signer line, such as `valid-before="20200101Z"`, for a key (#5855). `.gitleaks.toml` allows that pattern by line, and its old `[allowlist]` table moves to the `[[allowlists]]` form, which gitleaks needs for two lists.
