- **`open-interpretability next` draws explanations** (#3744, part C). An `explanation` draw explains a model's answer to a prompt from `data/explanation-prompts.jsonl`, narrates it and records it. A stale explanation is drawn again. Each unstudied pole or head that a recorded explanation cites gets an attribution-audit `explore` draw, so the loop drives explained answers toward VERIFIED. The loop posts an explanation draw as EXPLAINED.
