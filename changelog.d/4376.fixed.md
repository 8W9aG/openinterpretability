- Fixed: an external agent could lose a corrected answer (#4376). When an answer failed validation, the agent wrote the error and then deleted the response file. An answerer that wrote again as soon as it saw the error lost that answer. The agent then waited out its whole timeout, an hour by default. The bad answer is now deleted first. A stress test lost 496 of 500 answers before the fix and none after.
- Fixed: tests no longer start the real Chrome (#4376). `build` prints each paper's PDF by default, and two tests that ran it timed out under load.
