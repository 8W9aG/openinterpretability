- **A part-of-speech label set in every scan** (`openinterp/names.py`, `openinterp/evidence.py`, #3223). Each word's universal tag (UPOS) comes from the same spaCy pass as names, with the tagger added to its pipes. It is cached by the text's hash, so no new model is downloaded. A scan records how much part of speech explains of the pole: R², mutual information, and each tag's count, mean strength and active tokens. The proposer's prompt shows it. A study of 6 VERIFIED Qwen2.5-0.5B poles is in `docs/analyses/part-of-speech.md`.
