- **`explain --run`, `--complete` and `--record` no longer wait for CI** (#5826). Landing opens the PR ready for review and goes on at once. `auto-merge.yml` merges a qualified PR when CI passes, and a maintainer merges the others. Before, each landing could wait 45 minutes, so a run by a contributor whose CI needs approval took the longest and counted nothing.
- **A run counts the records of its open PRs.** The next draw and the coverage after the run see them, so a VERIFIED unit is not drawn again. No experiment's commit holds them. The explanation record lists them as `pending`, and its PR body and page show them.
