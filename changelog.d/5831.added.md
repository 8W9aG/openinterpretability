  - With no `--proposer`, `--reviewer` or `--provider`, and `claude` on `PATH`, `explain --run` runs each planned experiment in a headless Claude Code session, whose subagents answer. It still draws by coverage gain and measures the coverage between sessions. Without `claude`, it says what to do instead.
  - `scripts/experiment-loop.sh` and `explain --run` share one launcher, the new `open-interpretability claude-session`.
  - Inside Claude Code, the narrator is a subagent (`external/`) when `--narrator-model` isn't given.
  - The new `explain` skill runs a whole explanation in a Claude Code session: the plan, its experiments, the answer experiment, the narration and the record.
