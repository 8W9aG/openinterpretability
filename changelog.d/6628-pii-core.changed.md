- The site's redaction core now lives in `labinacan/site/pii.py`: the search's cache, `find_spans`, `redact_text`, `redact_tokens` and `scrub` (#6628). A project tells it where to keep matches on disk with `configure`. Without that, it keeps nothing on disk and redacts the same. The record scrubbing stays in `builder/registry_pii.py`, which gives the core this repo's cache folder and search name. `labinacan/cache.py` takes the cache base as an argument, and `core/cache_dirs.py` passes this repo's base.
