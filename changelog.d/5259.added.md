- **alphaXiv AI Track submissions** (#5259). `scripts/papers.py submit <slug>` writes the upload package of a published paper to `build/alphaxiv/<slug>/`. The package is the PDF that `make build` prints, and `submission.md` with each field of the form. alphaXiv has no upload API, so the maintainer approves the package and uploads it from the project account. `scripts/papers.py alphaxiv <slug> <url>` then records the URL in the paper's `CITATION.cff`, outside the frozen hash. The paper's page links it. The `release` skill prepares a package for each paper published since the last tag.
