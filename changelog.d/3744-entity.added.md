- **Explanations are records with their own pages** (#3744, part B). `open-interpretability explain --record` writes one to `wiki/explanations/<model>/<prompt id>/<UTC>.json`. It holds the prompt, the answer, the shares, prompt coverage, the mechanism with each unit's status at the time, and the narration. The site's *Explanations* pages show each prompt's newest record: the paragraph, the long form, then the mechanism with a link to each unit. A page is marked stale when a cited unit's status has changed since.
