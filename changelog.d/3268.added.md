- `scripts/cpu_acceleration.py` profiles CPU runs and times CPU options against float32 on an Apple M1 Max and a Linux i7-13700KF. Fewer threads on a shared machine, a fused GELU and compiling to C++ make forward passes faster within `reproduce`'s tolerance. Half precision is far slower on these CPUs, and it fails the tolerance. `docs/analyses/cpu-acceleration.md` has the results.
