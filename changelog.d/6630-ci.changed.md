- **CI's generic checks have a workflow of their own** (#6630). `.github/workflows/labinacan-ci.yml` holds the jobs that any autoresearch project runs: code changes, *Lint and tests*, mutation testing and accessibility. The jobs keep their names, so branch protection still finds *Lint and tests*. `ci.yml` keeps this project's jobs: experiment records, record changes, reproduction and the model cache. The generic workflow reads the project's packages with `make packages`, and runs `make project-lint` for the project's own checks, so it holds no value of this project. `tests/test_labinacan_config.py` checks that. `auto-merge.yml` waits for both workflows' runs when a PR leaves draft.
