- **Fix patches: a commit-like format for fixes to a base model** (#5229, part 1). `openinterpretability/patches/` adds the patch record, which names its base, its parents and an ordered list of declarative operations. The operations come from a versioned registry: weight edits, added neurons, layers and modules, pruning, gates, steering and clamps. The patch's id is its content hash. A patch applies in memory through hooks and removes exactly, and a zero-start check guards it. Patches have history like git commits: replay, log, diff, branches, merges, reverts and rebases. `main` takes only a fixed patch, and a merge checks for parameter, order and footprint conflicts. Commands come in part 2.
