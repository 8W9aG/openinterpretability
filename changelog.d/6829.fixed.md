- **Mutation testing no longer times out a mutant whose tests take no time** (#6829). mutmut gives a mutant (its tests' measured time + `timeout_constant`) × 15 × 2 CPU seconds. With the default of 1, a mutant whose tests measure 0 s had 30 s. A parallel run sometimes used more than that on the fork of each test process (SIGXCPU). So the same mutant was killed in one run and timed out in another. `[tool.mutmut] timeout_constant = 10` gives such a mutant 300 s. Before the fix, two of three runs of the 62 mutants of `labinacan/config.py` timed out one. After it, five runs killed all 62 each time.
