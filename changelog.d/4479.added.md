- Each explanation page has figures, drawn at build time from data that `explain --record` stores in the record (`ExplanationRecord.figures`). The first is the attribution graph. Then come the logit waterfall and the coverage against random units. Then each top unit's strength along the prompt, and the answer's top tokens before and after ablation. Last are the groups. The graph builds layer by layer, and the coverage figure moves too. Each animated figure has a pause button and a static last frame, and it stops under reduced motion. No figure rests on colour alone, and each has a text alternative and a table. The paper figures' SVG and motion helpers moved into the package (`openinterpretability.figures`), so both draw with one system (#4479).
