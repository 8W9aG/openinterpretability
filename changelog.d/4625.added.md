- A failed **Deploy registry** run now opens an issue, `Deploy registry failed on main`, or comments on the one already open. The issue has the failed jobs and steps and the last 60 lines of each failed log. A later good deploy doesn't close it. A failure that goes away by itself is a flaky deploy, so the issue stays open until someone fixes the cause. `scripts/issue_state.py` accepts the issue as automatic (#4625).
