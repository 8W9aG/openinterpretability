- A new paper, *Tuning or size? A matched random change for neuron explanations under instruction tuning*. It adds to each Qwen2.5 base model a random change with the instruct change's norm in every weight matrix, then tests each VERIFIED explanation again. On Qwen2.5-0.5B, the random change keeps 296 to 301 of 361 explanations, and the instruct change keeps 298. On Qwen2.5-1.5B, the random change keeps 72 or 73 of 75, and the instruct change keeps 65. `scripts/random_delta_keep.py` runs the test. It reads the probes in batches, and it reads the first-token check in one pass for all poles. `scripts/random_change_stats.py` gives the paired tests (#5154).
