- **Mutation testing of a branch's changes.** `make mutation BASE=origin/main` mutates the package files that the branch changes, and runs the tests that import them (#5856). It fails when a mutant survives or no test reaches one. Record an equivalent mutant on its line with `# pragma: no mutate, equivalent: <why>`. The `test-new-paths` and `work-an-issue` skills run it before a PR is opened.
