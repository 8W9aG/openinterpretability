- **One project config for labinacan** (#6629). `labinacan/config.py` reads the project's values from its `pyproject.toml`. `[project]` gives the command, the description, the URLs and the maintainer. A new `[tool.labinacan]` table gives the name, the package and the prefix of the environment variables. The environment variables, the feed's thread namespace, the social poster's user agent and two templates in `labinacan/` now read it. So `labinacan/` holds no value of this project, and `tests/test_labinacan_config.py` checks that. `core/project.py` keeps its names and reads them there. The built site is unchanged.
