- **Evidence branches only gain blobs** (#6166). `evidence_branch.push` used to replace `evidence/<branch>`. A second revision of one neuron reuses the experiment branch, so its push could drop a merged record's blob before the deploy had uploaded it. Then every code PR failed the experiment-records check. The push now keeps the blobs that the branch already holds, and leases on the commit that it read. If another push lands first, it reads the branch again.
