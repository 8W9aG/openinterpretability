- The package is published to PyPI as `open-interpretability`, on every GitHub release (`.github/workflows/publish.yml`, with the `PYPI_TOKEN` secret). Its command is `open-interpretability`, and `openinterp` stays as an alias for now. `pip install open-interpretability[site]` adds Pagefind for `build`. The wheel holds every template and data file that the code reads. After pulling, run `make install` once: a plain `uv sync` loses the `openinterp` command with the old distribution.
