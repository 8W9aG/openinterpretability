- **`explain --local`, and `open-interpretability explain-share`** (#5827).
  - `explain --run --local` and `--complete --local` run an explanation end to end in your own checkout, with no GitHub call: no claim, push or PR. Each experiment writes the same record, with the same inputs, into your `wiki/`. The coverage counts it at once.
  - The explanation record lists those experiments under `run.local`, and its page says how many are local.
  - `explain-share <record>` opens one PR with the record and every local experiment it used. As for any landing, it doesn't wait for CI. It names any unit that gained a record on main since.
  - `--land` stays the default.
