- **Renamed: the package is `openinterpretability`, not `openinterp`** (#4089). The old name belongs to an unrelated project. Imports change from `openinterp` to `openinterpretability`. The command (`open-interpretability`) and the PyPI name are unchanged. `OpenInterpError` is `OpenInterpretabilityError`.
- **Renamed: every `OPENINTERP_<X>` environment variable is `OPENINTERPRETABILITY_<X>`.** For this release, an old variable that is set is still read, with a warning, when the new one is unset. The variables are `AGENT_MODEL`, `AGENT_PRODUCT`, `ANE_PREPARE_MINUTES`, `AUTO_SIGN`, `BATCH_SCALE`, `BUILD_CACHE`, `CHROME`, `CONTRIBUTOR`, `COREML_CACHE`, `COREML_CACHE_GB`, `CORPUS_CACHE`, `CORPUS_CACHE_GB`, `COSTS_LOG`, `CPU_BUSY_PERCENT`, `CPU_THREADS`, `DEVICE_FORCE`, `DEVICE_LEASES`, `DRIVER_MODEL`, `DRIVER_PROVIDER`, `EVIDENCE_DIR`, `EXCHANGE_DIR`, `EXCHANGE_TIMEOUT`, `FIRST_POSITION_CACHE`, `GPU_BUSY_PERCENT`, `HEAVY_LOCK`, `HEAVY_LOCK_FILE`, `HEAVY_LOCK_HELD`, `MEANS`, `MEMORY_GB`, `MODEL_ALIASES`, `MPS_START_SECONDS`, `NEURONPEDIA_CACHE`, `OFFLOAD_EVIDENCE`, `PAUSE_FILE`, `PII_CACHE`, `PRIOR_ART`, `PROGRESS_SECONDS`, `PR_AUTHORS_CACHE`, `ROTATION_CACHE`, `SCAN_CACHE`, `SCAN_CACHE_GB`, `SIGNING_KEY`, `SITE_URL`, `STOP_FILE`, `UPLOAD_WORKERS`.
- The signing key's default is `~/.ssh/openinterpretability_signing`, and keychain items are `openinterpretability-<provider>`. The old key file and items are still read when the new ones don't exist. A machine that has only `~/.cache/openinterp` keeps using it, so running loops share their locks. Records keep the field `openinterp_version` and the signing namespace `openinterp-record`, because their signatures cover them. `make lint` fails if the old name comes back (`scripts/check_old_name.py`).
