- **CI skips the reproduce job and CodeQL on PRs that only add signed records** (#4669). *Record changes* runs a gate from the base branch (`openinterpretability/signing.py`, `needs_reproduction`). It skips *Reproduce records* only when every changed record is an experiment record whose signature verifies in its key's window. Any other case, or any error, still reproduces. `reproduce` now counts signed records apart: `1 signed (reproduction skipped). 0/0 record(s) reproduced.` CodeQL moves from default setup to `.github/workflows/codeql.yml`, with the same languages and weekly schedule, and skips PRs that change only `wiki/`.
