- **The project has a mark** (#3289). It is a green square with a 3 × 3 grid of cells, each filled from the bottom like the pieces maps. The site shows it in place of the `⊕` placeholder, and as the favicon. Each page has Open Graph and Twitter-card tags with a 1,200 × 630 image (`assets/og.png`). The README shows the logo. The accent colour has one name, `brand`, defined in `builder/palette.py`, where the templates named Tailwind's `emerald` in 95 places. `scripts/brand_images.py` draws the PNGs from the SVG mark.
