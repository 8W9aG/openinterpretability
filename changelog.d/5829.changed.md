- **`explain` builds its own corpus when `--corpus` isn't given** (#5829). Before, it read `corpus.jsonl`, which a fresh clone or a pip install doesn't have, so `explain` failed at once. Now it uses the registry's scan corpus, the first 500 documents of pile-10k at a pinned commit. It uses `./corpus.jsonl` when that file holds the same bytes. Otherwise it builds the corpus once into the rebuilt-corpora cache and reuses it, so every explanation of a model keeps the same means. `--corpus` still overrides it.
