- `explain --record` lands the explanation record as its own PR, as an experiment lands. It goes on its own branch in the loop's worktree, passes `open-interpretability check`, opens a ready PR and merges on green. The PR body gives the explained share and the prompt coverage against random units. It also says what the run did, with links to the experiment PRs it landed. A second run on the same prompt and model updates its page rather than adding one. `--no-land` writes the record locally, as before (#4475).
