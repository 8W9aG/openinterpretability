- The deploy's site build runs under a 14.5G memory cap, plus 2G of swap (`scripts/capped.sh`). Above the cap, the kernel stops only the build, and the step fails at once with an out-of-memory error. Before, a build that ran out of memory killed the runner agent too. The run then hung for about 45 minutes with no reason in its log. The step prints the peak process memory of the build and its workers, and warns above 13G. On a runner the build peaked at 13.9 GiB. The build's forks now run under `gc.freeze()` (#4592).
