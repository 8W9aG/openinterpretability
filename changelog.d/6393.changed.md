- Headless `claude -p` sessions (`explain --run`, `scripts/experiment-loop.sh`) now load only the project's settings. They may run `uv run open-interpretability`, but not all of `uv run`. They are denied workflow runs, `gh api`, merges, secrets, releases, free Python, git configuration, and forced or deleting pushes. `$OPENINTERPRETABILITY_SESSION_GH_TOKEN` gives the sessions their own GitHub token. The loop script's sessions now leave the merge to `auto-merge.yml` (#6393).
