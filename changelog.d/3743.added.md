- **`open-interpretability explain --level long|paragraph` narrates the explanation** (#3743). A narrator agent reads only the evidence: the shares, prompt coverage, units, groups, paths and next experiments. Only VERIFIED explanations are in that evidence. It writes a long form that follows the computation, and a one-paragraph summary. Each claim must cite a unit, and the text must say how much is unexplained. The output warns about citations that the evidence doesn't hold. `--json` keeps the evidence, the narrative, the narrator model and its costs. The `explanation-narrator` subagent answers an `external/` narrator from Claude Code.
