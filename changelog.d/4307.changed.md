- The paper PDFs are set in Computer Modern, the LaTeX typeface of arXiv papers. That covers text, headings, page numbers, code and the figures' text. The fonts are bundled and embedded: CMU (SIL OFL) for text and code, and Latin Modern Math (GUST licence) for the symbols CMU lacks. `pdffonts` lists no system font in any paper's PDF. Superscript digits print as raised plain digits, as LaTeX sets them (#4307).
