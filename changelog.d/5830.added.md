- **`explain` asks before it spends LLM tokens, and shows where it is** (#5830).
  - Before `--run`, `--complete` or a narrated `--level` calls an LLM, it says what will run and estimates the tokens and the cost from the model's recent experiments. Then it asks, with no as the default.
  - `-y`/`--yes` skips the question. With no terminal and no `--yes`, it refuses, and so never hangs. The planner's explanation draws pass `--yes`.
  - Each stage prints `[i/N]` as it starts. On a terminal, every long loop shows a bar with the time left. These are the baselines, the random sets, the gains, the plan and the minimal set. In a run, each experiment says its count, unit and attempt.
  - `--quiet` turns the stage lines and bars off, and `--json` implies it.
