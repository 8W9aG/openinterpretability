- **Repeated mutation runs** (#6359). `make mutation RUNS=5` runs mutation testing 5 times, each from a clean `mutants/` and in its own test order (pytest-randomly seeds 1 to 5). It reports each run's counts, and fails when a mutant fails in a run or changes its result between runs. The `test-new-paths` skill now says that a surviving mutant in a changed verdict file blocks the PR.
