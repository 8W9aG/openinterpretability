- **The Makefile has a generic part** (#6630). `labinacan.mk` holds the targets that any autoresearch project uses, such as `install`, `test`, `coverage`, `mutation`, `lint`, `vale`, `ste`, `build`, `css` and `serve`. The Makefile sets this project's values (`DIST_NAME`, `PACKAGES`, `TEST_WRAPPER`, `CSS_MODULE`, `BUILD_COMMAND` and `PROJECT_LINT`), includes it, and keeps its own targets. Each target runs the same commands as before, as `make -n` shows. In `make lint`, the check of the old package name now runs earlier, in `project-lint`. `tests/test_labinacan_config.py` checks that `labinacan.mk` holds no value of this project.
