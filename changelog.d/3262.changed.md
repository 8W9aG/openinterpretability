- `openinterp sisters` searches every model pair in one search of four stages. Each stage reads each model once, and only one model is loaded at a time. Hooks keep only the rows that a stage reads, and rotations and correlation sums stay under a memory budget. On 40 documents with all six pairs, it took 14.3 minutes against 26.0, at a peak memory footprint of 18.4 GB against 51.1 GB. The rows are the same.
