- **`make lint` asks for a comment in each long function body** (#3159). `scripts/check_body_comments.py` fails on a function whose body, after its docstring, runs to 20 lines or more with no `#` comment. It is ratcheted in: the 272 functions that broke the rule are listed in `scripts/body_comments_baseline.txt`, and the list may only shrink. The `commenting` skill says what such a comment should say.
