- Releases follow Semantic Versioning. A new `semantic-versioning` skill, which the `release` skill runs, decides the next version with its reasons (#3173). It finds breaking changes to the record schema, CLI, Python API and protocol. `python3 scripts/changelog.py next` proposes the version from the waiting fragments. A breaking change is a `removed` fragment, a bullet marked `**Breaking.**` or a protocol change. While the version is 0.x it bumps the minor number, and any other change bumps the patch.
