- CI runs mutation testing on the package files that a pull request changes. A surviving mutant fails the job, and the job summary lists it. The maintainer's PRs skip the job, because the maintainer runs it before opening them. Wiki-only PRs skip it too. A second job, *Mutation testing ran locally*, fails a maintainer PR that changes package code unless its body records a local run with no survivor. The `work-an-issue`, `next-issue` and `release` skills say when to run it (#5857).
- `make mutation BASE=origin/main` runs only the mutants in the functions that the branch changes, at most 100 of them, a seeded sample. On #6459's five files that is 7.7 minutes, against about an hour for the whole files (#5857).
- mutmut 3.8.1 is in the `dev` dependency group, so `make mutation` and CI need no `--with` (#5857).
