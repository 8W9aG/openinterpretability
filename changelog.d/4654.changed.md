- **Standing: a failed rival no longer overturns a verified claim** (#4654). When a unit's newest hypothesis is not VERIFIED but an earlier hypothesis was, the unit is now CONTESTED, not REJECTED or NEEDS_REVISION. It does not count as verified while it is contested. A new hypothesis that reaches VERIFIED settles it. The unit page names both hypotheses, and the planner draws a revision for such a unit, not one more review. Standing reads verdicts and never changes one, so `PROTOCOL_VERSION` is unchanged. In the registry, 9 units changed from NEEDS_REVISION or REJECTED to CONTESTED.
