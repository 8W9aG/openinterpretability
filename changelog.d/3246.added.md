- **`openinterp loop`** (`openinterp/experiment_loop.py`, `openinterp/cli_loop.py`, `docs/experiments.md`, #3246). It runs experiments back to back from the CLI, with LiteLLM proposer and reviewer models and no Claude Code session. Each iteration resets a detached worktree, draws, claims, runs the draw's steps in-process with the model kept loaded, posts and lands the PR. It honours `openinterp pause`, the stop file and provider rate limits.
- **A revision's proposer sees the record it supersedes** (`openinterp/revision.py`, #3246). That is the old hypothesis, its verdict, its failed gates and the probes it got wrong.
