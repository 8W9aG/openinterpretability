- `explain --run` with no number runs the plan until the explained share reaches `--target`, or no work is left. `--run N` stops after N experiments too. Unit and superposition experiments run together, by the prompt coverage each would add. After each landed experiment, it measures the share again from the registry and prints it. At the start it says what is blocked, which circuits wait for an agent to write their task, and the most the run can reach. If the target is out of reach, the run stops there (#4473).
