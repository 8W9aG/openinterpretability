## Summary

**Claim.** Small ReLU networks trained on sparse synthetic features store more features than they have dimensions. The authors call this *superposition*. It explains polysemantic neurons in these models. Whether a feature is dropped, put in superposition or given its own dimension changes sharply, like a phase change. With a privileged basis, both monosemantic and polysemantic neurons form, and some computation is possible in superposition. The authors say that it is "very unclear what to generalize to real networks".

**Method.**

- **Data.** Each input dimension x_i is a "feature". It is 0 with probability S, the sparsity, and otherwise uniform on [0, 1]. Each feature has an importance I_i that weights its squared error.
- **Models.** A *linear model*, x′ = WᵀWx + b. A *ReLU output model*, x′ = ReLU(WᵀWx + b). A *ReLU hidden layer model*, which adds a ReLU on h = Wx and so gives a privileged basis. An *absolute-value model*, h = ReLU(W₁x) and y′ = ReLU(W₂h + b), with features on [−1, 1] and target |x|.
- **Measures.** ‖W_i‖ says whether a feature is represented. Σ_{j≠i}(Ŵ_i · W_j)² says how much it shares its dimension. D* = m / ‖W‖²_F gives "dimensions per feature". A per-feature dimensionality D_i = ‖W_i‖² / Σ_j(Ŵ_i · W_j)².
- **Theory.** The loss is split by the number of active features. For 1-sparse inputs, the loss is like a generalised Thomson problem: points packed on a sphere. Closed-form losses for a few weight configurations give a "toy model of the toy model" phase diagram.
- **Other tests.** Analytic L2 adversarial attacks, adversarial training, correlated and anticorrelated feature sets, and the change of feature dimensionality over training.
- **Baselines.** The linear model, which never uses superposition. No real network is measured.

**Findings, as the source reports them.**

| Setting | Result |
| --- | --- |
| n = 20 features, m = 5 dimensions, I_i = 0.7^i | The linear model "always learns the top-m most important features". As sparsity rises, the ReLU output model puts features in superposition, less important ones first, at first as antipodal pairs |
| n = 80, m = 20, I_i = 0.9^i | "Essentially a rescaled version" of the n = 20 result |
| n = 2, m = 1, second feature's importance 0.1 to 10, sparsity 1.0 to 0.01 | Ten models per point, the highest-loss one discarded. Both the empirical and the theoretical diagrams show a phase change, and the theoretical one is first-order |
| Uniform superposition, n = 400, m = 30, I_i = 1 | D* is "sticky" at 1 and 1/2. The 1/2 point is antipodal pairs |
| Per-feature dimensionality | Clusters at ¾ (tetrahedron), ⅔ (triangle), ½ (antipodal pair), ⅖ (pentagon), ⅜ (square antiprism) and 0 (not learned) |
| n = 5, m = 2, 1 − S = 0.05 | A regular pentagon. A sparser feature lets the others close in. Past a point it collapses to a pair of digons with that feature at zero, a first-order phase change |
| Correlated features | Prefer to be orthogonal, then side by side. Without room, they collapse into their principal component. Anticorrelated features prefer negative interference, ideally antipodal |
| Adversarial examples, L2 attack of at most 0.1 of the mean input norm | Vulnerability "sharply increases as superposition forms (increasing by >3x)". It tracks features per dimension |
| Adversarial training | Reduced superposition, but removing it needed attacks of 80% of the input's L2 norm |
| Learning dynamics | Features "jump" between dimensionalities. Each jump goes with a sudden drop in the loss |
| ReLU hidden layer, n = 10, m = 5, I_i = 0.75^i | 1,000 models per setting, the lowest loss shown. Neurons shift from monosemantic to polysemantic as sparsity rises. Both kinds can be in one model |
| The same model, given a hidden bias | It sets all biases positive and so avoids the ReLU. The authors call this "a significant mark against studying this toy model" |
| Absolute value, n = 3, m = 6 | One "positive side" neuron ReLU(x_i) and one "negative side" neuron ReLU(−x_i) for each feature |
| Absolute value, n = 100, m = 40, I_i = 0.8^i | Dense features give one feature per neuron. Sparse features give superposition, so computation happens in superposition. Neurons of the most important features tend to be monosemantic |
| The same model, polysemantic neurons | Many have one "primary" feature with a large weight, and "secondary" features with smaller weights. So the largest activations are all or nearly all the primary feature, and weaker ones are "much more polysemantic" |
| Compressed-sensing bound | m = Ω(−n(1 − S) log(1 − S)). So the number of features is linear in m, modulated by sparsity |
| Independent replications | Redwood Research (Sachan), DeepMind (McGrath) and OpenAI (Wu and Mossing) replicated named sections from an early draft. McGrath's exact n = 2, m = 1 solution found a further phase, W₁ ≃ W₂ ≃ ½, without correlated features |

**The paper's view of real networks.** The authors list four observations that their models agree with. Polysemantic neurons exist. Clean and polysemantic neurons share a layer. InceptionV1 has more polysemantic neurons in later layers. Neurons in the first MLP layer of transformer language models are, in the authors' experience, "often extremely polysemantic". The introduction says that in large language models "it actually seems rare for neurons to correspond to clean features". They expect superposition and the monosemantic–polysemantic split to carry over, and the geometry and learning dynamics much less so.

## Where the claims go beyond the evidence

- **No real network is measured.** All results are on synthetic data with known features. The bridge to real models is four qualitative observations, and the claim about LLM neurons comes from the authors' experience, not from a count. The authors state this limit themselves, in the key results and in the discussion.
- **The real-model check can't fail.** The authors' "best validation" is that the toy models agree with known facts about polysemanticity. Each of those facts came before the models, so the check only shows that the models can reproduce them. The paper tests no new prediction about a real network.
- **One data distribution.** Features are independent, uniform on [0, 1] and of equal sparsity in most experiments. Footnote 8 calls the uniform choice "arbitrary". Redwood's replication found that the phase diagrams "look quite different depending on the activation function".
- **Best of many runs.** The ReLU hidden layer figures show the lowest-loss model of 1,000. The phase diagrams drop the worst of ten. Neuron order was chosen by hand, and polysemanticity in the absolute-value plots was "judged by eye". The authors say that typical runs are similar, but they give no spread.
- **Few statistics.** No result has an interval or a count of seeds, except the ten models per point of the phase diagrams. The adversarial ">3x" has no spread.
- **The privileged-basis model has a known flaw.** The ReLU hidden layer model avoids its ReLU when it can, as the authors say. The absolute-value model fixes this, but its sizes were "chosen to illustrate the phenomenon".
- **Dangling references.** The text points to an appendix on multidimensional features that the published page doesn't contain. It also points to a "feature packing principle suggested above" that no earlier section states. The page gives 14 September 2022, and arXiv gives 21 September.

## Use in this repo

**The repo's premise is the paper's open question.** The paper asks: "If X% of the model is interpretable neurons", how much do we understand from them? Research question 1 (`docs/research-questions.md`) measures that X. On 2026-11-14, 25.1% of 1,711 random audited poles were VERIFIED on the first reading, and 27.9% standing (`docs/analyses/registry-stats.md`). That share lies between Cammarata's essay, about 90% with one main job (`native-neuron-audit` skill), and this paper's "rare" for LLMs. The paper doesn't tell the two causes of a failed audit apart: superposition, or a poor tool. So it can't say which part of the other 72% is which. The audit skill's checklist exists to remove the tool part first.

**One real-model claim can be checked against the registry, and it doesn't hold for Qwen.** The paper says that first-layer MLP neurons are "often extremely polysemantic". In `registry-stats.md`, Qwen2.5-0.5B's layer 0 has the third highest VERIFIED share of its 24 layers: 14 of 31, 45%. GPT-2 small's layer 0 is low, 8 of 44 (18%), but GPT-2's first three layers are all low. No layer effect is detectable in either model (p = 0.075 and 0.23). The paper's InceptionV1 pattern, more polysemantic neurons deeper, is not seen either. By quarter of depth, the pooled shares are 26.1%, 25.5%, 26.6% and 22.3% (p = 0.46).

**The rotated-basis null tests the paper's privileged basis.** The paper says that a basis is privileged when an activation function breaks the rotation symmetry. In a non-privileged basis, a random rotation M with M⁻¹ in the next weights gives an identical model. `docs/analyses/null-calibration.md` audits rotated units of this kind. Native positive poles reach VERIFIED 18 of 30 times, and rotated units 1 of 30 (sign test p = 1.5 × 10⁻⁵). That page cites Elhage et al. (2021) for the idea. This paper states the same argument. It also says what a privileged basis doesn't give: "having a privileged basis doesn't guarantee that features will be basis-aligned".

**A repo paper tested the negative-bias idea, and width didn't move the rest.** The paper shows that a negative bias turns small positive interference into negative interference, free under a ReLU in the 1-sparse case. `papers/why-neurons-rest/` applies this to real MLPs. If neurons rest low to filter interference, narrower MLPs should rest lower, and they don't. That paper counts this against one version of the idea, not against the toy result.

**Primary and secondary features bear on the active line.** The absolute-value model's polysemantic neurons have one primary feature in their largest activations and other features in their weaker ones. The registry counts a probe as active at 0.25 × the pole's own maximum (`explanation-simulation-scoring` skill). So a VERIFIED explanation may describe only a primary feature, with secondary features below the line that the protocol never sees. The paper's model predicts that this happens most for poles of rare features. Follow-up 1 below would measure it. `neurons-as-an-interpretable-basis.md` already reviews percentile-band ablations on another model, which bear on the same question.

**The superposition entity has no ground truth yet.** The protocol's superposition is a sparse direction over one layer's neurons (`docs/PROTOCOL.md` §1, `openinterpretability/explain_groups.py`). The paper's privileged-basis models make features "correspond to sets of neurons", which is close to that definition. `data/superpositions/Qwen--Qwen2.5-0.5B.jsonl` holds 30 directions from two finders (`docs/analyses/superposition-finders.md`). The registry audited four of them (`wiki/experiments/Qwen--Qwen2.5-0.5B/`). L15/Sdc03b97411c7 stands VERIFIED, and L9, L14 and L20 are NEEDS_REVISION. The two finders share 51 of 95 neurons, but their weight vectors have cosines near zero. The paper says that toy models can be studied only because "we do know what the features are". Follow-up 2 below would give the finders that check.

**Interference and change after the loss settles (#4782).** The paper reports features that "jump" between configurations during training, each jump with a small drop in the loss. It suspects that smooth loss curves in larger models hide "many small jumps". `papers/neuron-development/` finds that Pythia-70m's VERIFIED poles keep changing after the loss settles by step 16,000. Their median correlation with the final form is 0.62 there, and adjacent checkpoints correlate at a median of 0.78 to 0.82. Jumps and steady drift would give different per-pole trajectories. That test belongs to open issue #4156 (adjacent-checkpoint correlations), and the paper is evidence for asking it there. The paper's learning-dynamics results are the ones its authors trust least, so this is a hypothesis, not a prediction.

**Stability under fine-tuning fits a small perturbation, with a caveat.** In the paper, changing one feature's importance or sparsity deforms the geometry smoothly until a critical point, then snaps it. `docs/analyses/base-instruct.md` finds that 38 of 43 Qwen2.5-1.5B hypotheses keep on the instruct model, with median activation correlation 0.983. That agrees with a fine-tune that stays away from a critical point. But the paper's phase changes are in toy models with known features, so nothing here predicts which poles would snap. The fix campaign is the maintainer's, so this page reports evidence only.

**Correlated features suggest sisters among superpositions.** The paper finds that correlations, not chance, decide which features share a neuron. So polysemantic groupings may repeat across models. `docs/analyses/sister-neurons.md` finds sisters for 53 of 259 VERIFIED Qwen2.5-0.5B poles (20%) in Qwen2.5-1.5B. Open issue #4439, sister superpositions, is where this prediction would be tested.

**A question for the maintainer.** Suppose a VERIFIED pole's weaker activations, below 0.25 × max, follow a second feature. Should the record say so, or is that a matter for the polysemantic experiment class (#3215, closed)? Any change to what VERIFIED means needs a `PROTOCOL_VERSION` bump (`docs/PROTOCOL.md` §6).
