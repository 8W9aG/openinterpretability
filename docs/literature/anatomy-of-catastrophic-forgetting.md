## Summary

**Claim.** When a network trains on one task and then on a second, the layers nearest the output change most. They cause most of the forgetting. Two common ways to reduce forgetting, elastic weight consolidation (EWC) and a replay buffer, act mainly by keeping those higher layers stable. Forgetting is worst when the two tasks are of intermediate similarity.

**Method.**

- **Tasks.** *Split CIFAR-10*: two tasks of five classes each, with one output head per task and a shared body. *Split CIFAR-100 distribution shift*: one head classifies CIFAR-100 superclasses, and the second task changes which subclasses make up each superclass. The model does not know which task it is on.
- **Networks.** A VGG of five stages with no batch norm, with and without two fully connected layers. A ResNet of four stages with two residual blocks each. A DenseNet of four dense blocks. A *stage* is the paper's unit of depth, a block of convolutions.
- **Training.** SGD with momentum 0.9, batch size 128 and no learning-rate schedule. On split CIFAR-10, 30 epochs per task, with a learning rate of 0.01 (VGG) or 0.03 (ResNet and DenseNet). Weight decay is 1e-4, and there is no data augmentation. Each network trains until it fits its training set. The paper reports four splits of CIFAR-10.
- **Measures of where forgetting happens.** Linear centered kernel alignment (CKA) between each stage's activations before and after task 2. CKA doesn't change under an orthogonal transform or an isotropic scale of the features, but it does change under other linear transforms. *Layer freezing*: freeze the lowest N stages during task 2, and read task 2 accuracy. *Layer reset*: after task 2, set a block of stages back to their values after task 1, and read task 1 accuracy. The block grows from the top or from the bottom.
- **Further tests.** Reset and retrain the top stages (Appendix G). A linear classifier on the post-forgetting activations of all stages (Appendix H). Its control uses the activations of a network at initialisation, which the paper calls a *random lift*. Task-specific top stages (Appendix E). Network width (Appendix C). Training the new head alone before the full network, *headfirst training* (Appendix D).
- **Mitigation.** EWC, with the diagonal Fisher information from 200 samples, at several strengths. A replay buffer at replay fractions 0 to 0.4.
- **Semantics.** Sequential binary tasks of two animals or two objects (Setup 1). A four-class task of two animals and two objects, then a binary task (Setup 2). A third *other* class of random CIFAR-10 images during task 1. A task 2 data set that mixes task 1 and task 2 images and labels by a parameter λ, as in mixup.
- **Analytic model.** The *frozen feature model* keeps all features fixed after task 1 and lets only the final layer train. Then the feature overlap Θ(x, x′) = Σ_μ g_μ(x) g_μ(x′) bounds the change in the task 1 logits. The overlap is between task 1 test data and task 2 training data.

**Findings, as the source reports them.**

| Setting | Result |
| --- | --- |
| CKA before and after task 2, split CIFAR-10 and CIFAR-100, VGG, ResNet and DenseNet | "lower layers representations remain stable through training on the second task, whereas higher layer representations change significantly" |
| Layer freezing from the lowest stages | "freezing the lowest few layers has little effect on accuracy on the second task" |
| Layer reset from the top (head excluded) | Gives "a significant increase in accuracy in the first task". Reset from the bottom gives less |
| Reset and retrain, split CIFAR-10 | "even retraining the network with all but the last couple of layers frozen recovers nearly the pre-forgetting performance". Some runs exceed it |
| Task-specific stages, all three networks | Two task-specific top stages recover "a significant fraction of the forgotten task performance" |
| EWC and replay buffer, ResNet in the main text, VGG and DenseNet in Appendix F | Stronger mitigation gives higher CKA, "particularly pronounced for deeper representations" |
| Network width, split CIFAR-10, about a tenfold range of parameters | Forgetting showed "a minimal dependence on network width" |
| Headfirst training up to five epochs | Less forgetting, with a negligible effect on the new task |
| Linear classifier on post-forgetting activations (Table 1) | DenseNet 0.802, ResNet 0.7592, VGG 0.7896 accuracy |
| Same, before forgetting / after forgetting / random lift (Table 1) | DenseNet 0.869 / 0.4754 / 0.447. ResNet 0.7714 / 0.5924 / 0.4198. VGG 0.7970 / 0.5877 / 0.543 |
| Linear classifier weights by layer (Appendix H) | Before forgetting, most weight is on the final layers. After forgetting, it moves to earlier layers |
| CKA of the readout head before and after task 2 (Table 2) | No headfirst training: VGG 0.147 ± 0.051, ResNet 0.183 ± 0.001, DenseNet 0.162 ± 0.008. Five epochs headfirst: 0.550 ± 0.029, 0.673 ± 0.010, 0.700 ± 0.012 |
| Setup 1, sequential binary tasks | "semantically similar tasks lead to less forgetting" |
| Setup 2, four classes then two | The classes dissimilar to task 2 lose less than the similar ones |
| Mixed task 2 data, by λ | "the most extreme forgetting happens for intermediate similarity" |
| CIFAR-100, mammal subclasses changed | Of the four unchanged superclasses, Large Carnivores, the other animal class, "suffers the most" |
| Frozen feature model with orthogonal features (Appendix K) | No forgetting, although the final-layer weights change a lot. So a stable final layer is not necessary to stop forgetting |

## Where the claims go beyond the evidence

- **"Higher layers" rests on curves that the text doesn't quantify.** The main claim comes from CKA, freezing and reset curves in Figures 1 to 3. The text gives no CKA value for any stage, and no difference between the top-down and bottom-up reset curves.
- **No seeds or intervals for the main results.** Table 2 has ± values, but the paper doesn't say over how many runs. The CKA, freezing, reset and semantic results have no spread, no count of runs and no tests. Table 1 has one value for each cell.
- **Small vision networks on CIFAR only.** The networks have four or five stages. Every result is on CIFAR-10 or CIFAR-100. Appendix B says that results common to the three networks are likely to generalise, but they are three convolutional networks on one kind of data.
- **"Higher layer" means stage, not unit.** CKA compares a whole stage's representation. It says nothing about whether single channels keep what they compute.
- **The semantic results are mostly single comparisons.** Setup 1 and Setup 2 each compare a few class pairs. Appendix J reports one exception, VGG's truck class in Setup 2. The λ result is one curve.
- **The analytic model assumes the main finding.** The frozen feature model freezes every layer below the head, by the authors' own choice, after the CKA results. The bound then shows that overlap is necessary for forgetting in that model. It doesn't test whether real networks forget through the head alone.
- **No released code.** The paper names the library that it built on, but gives no link to its own code or configurations.
- **Credit.** The authors use three different tests of where forgetting happens, and the tests agree. Appendix H has a null: the random lift checks that a linear classifier on many activations isn't simply separating the data by its dimension. The authors also say that the task-specific stages of Appendix E are evidence, not a proposed method. Appendix K gives a case where forgetting stops with no stable top layer, which limits their own conclusion about mitigation.

## Use in this repo

- **The registry's nearest measure is of units, not layers.** [`docs/analyses/base-instruct.md`](../analyses/base-instruct.md) tests VERIFIED hypotheses again after instruction tuning. On Qwen2.5-0.5B, 252 of 311 keep (81%, 95% CI 76–85%), and each pole's activation correlates with its instruct form at median r 0.974. The paper measures a whole stage with CKA, which doesn't change when the basis rotates. A pole's Pearson r does change when the basis rotates. So our measure is stricter, and it can fall where CKA stays high.
- **Depth on Qwen2.5-0.5B doesn't follow the paper's order.** In `base-instruct.md`, 104 of 112 poles keep in the first third of the layers. In the middle third 63 of 92 keep, and in the last third 85 of 107. We computed the median correlation by third from `base-instruct-0.5b.jsonl`. The bounds are depth below 1/3 and below 2/3. That gives the same counts as the page. The medians are 0.982, 0.962 and 0.973. So the first third changes least, as the paper finds for lower layers. But the middle third, not the last, changes most. Layer 11 keeps only 3 of 8 poles. These are our numbers, not the page's, and they come from one run with no interval.
- **The two settings differ in ways that can explain this.** Instruction tuning is not a second task on disjoint classes, with a new head. The transformer has a residual stream, and the paper's networks have four or five stages. So a transformer's last layers may not play the role of a CNN's top stages. The paper also lets each task fit its training set, and we don't know the Qwen tuning schedule.
- **Pretraining formation by layer is a different question.** [`papers/neuron-development/`](../../papers/neuron-development/README.md), Table 2, follows Pythia-70m's poles through pretraining. Layer 0's poles take their final shape first, at median correlation 0.90 at step 16,000. Layers 1 to 5 are at 0.60, 0.46, 0.61, 0.72 and 0.53. That is the order in which units form, not what a second task changes. The two results agree only in that the lowest layer is the most stable. Neither one shows a steady rise in change with depth.
- **A pole can keep its explanation while its downstream use changes.** Appendix H finds that a linear classifier on post-forgetting activations recovers most of the lost accuracy. That is 0.7592 against 0.7714 before forgetting for ResNet. So the information stays and the readout changes. This agrees with `base-instruct.md`, where the poles barely move. It also warns that a pole that keeps its explanation does not show that the model still uses it in the same way. The registry tests what a pole computes, not what reads it.
- **EWC stabilises the deep layers, which bears on #5118.** #5118 asks whether diagonal Fisher importance predicts which poles keep. The paper finds that EWC, which weights its penalty by the diagonal Fisher, mainly keeps the deeper stages stable. It doesn't report the Fisher values by stage. So it gives #5118 a reason to report Fisher importance by depth as well as by pole. We add no comment to #5118 from this page. The issue already covers the measure.
- **Intermediate similarity bears on the side effects of a fix.** The paper finds the most forgetting when the new data partly overlaps the old. [`complementary-learning-systems.md`](complementary-learning-systems.md) gives the same warning for focused learning of one fact. A fix of the #4781 " days" error trains on data close to prompts where the old behaviour is right. So those prompts are where the paper predicts the most damage. Which prompts a fix must keep is the maintainer's question. We open no issue for it.
- **Layer reset is a cheap test that the registry doesn't run.** The paper sets a block of layers back to their pre-task values and reads the result. For Qwen2.5-0.5B and its instruct model, the same swap would show which layers carry the change in a pole's readings. That is a measurement, not a fix. We propose it below with layer-level CKA, as one follow-up.
- **The sister search already has a null that CKA lacks.** [`docs/analyses/sister-neurons.md`](../analyses/sister-neurons.md) compares each match with a randomly rotated basis, at median r 0.08. A per-layer CKA between base and instruct would need a null of its own, such as CKA against a model at initialisation. That is the paper's random-lift idea.

**Proposed follow-up (not opened).** *Layer-level CKA between Qwen2.5-0.5B and Qwen2.5-0.5B-Instruct, beside the per-pole correlations of `base-instruct.md`.* `area: research questions`, `priority: low`. It would compute linear CKA for each layer's MLP activations over the same 20,000-token sample, with a random-initialisation null. It would also put blocks of base layers into the instruct model, and read the poles again. It would test whether the middle third's lower per-pole correlation is a change of the whole layer or a rotation within it. It cites this page.
