# Patchscope readout as a blind proposer baseline

Generated by `openinterp patchscope-baseline`; do not edit. Method: `openinterp/baseline.py` and docs/PROTOCOL.md §4.

Each unit's readout becomes one explanation by a rule fixed before scoring: the `category` prompt at the lowest layer read, at ×2 the replaced norm, as `Fires on tokens related to "<reading>".`. It is scored on the same held-out windows as the agent's explanation. Detection and fuzzing pair only experiments whose agent explanation was judged by the same model as the baseline's (49 of 99); embedding uses the record's own encoder. The sign test counts experiments, and a unit with several experiments counts more than once.
