# This project's priorities

The `next-issue` skill reads this file. It is this project's part of the skill (#6631).

The north star is total interpretability of open models (`docs/research-questions.md`, question 0).

- **urgent:** it breaks the registry, CI, a release, or the correctness of stored records.
- **high:** it changes whether verdicts can be trusted (protocol validity, false positives), or it removes a bottleneck to more VERIFIED units.
- **low:** every `area: models` issue, until each configured model reaches `coverage_target`.
