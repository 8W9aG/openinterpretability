## Hypothesis

> The pole fires at the close of a control-flow branch in code: it peaks on the last token(s) before the `}` (or the Python dedent) that ends an `if`/`else`/loop body, and on the `else` / `end if` / `} else {` that immediately follow that boundary, most strongly when the branch is a decisive early exit (`return`/`break`/`throw`), less for loop bodies, and near baseline for branch-free code. It is retrospective and content-weighted: it integrates the branch body already read (swapping `return true;` for `y++;` in the same slot cuts it ~2.5x even though the next token is `}` either way, and the pole's ablation moves next-token log-probabilities by only KL~1e-5), and it also lifts, more weakly, on prose that spells out the same 'if X, the function returns Y' relation.
