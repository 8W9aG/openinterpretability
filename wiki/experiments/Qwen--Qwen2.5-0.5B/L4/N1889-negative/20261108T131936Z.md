## Hypothesis

> The negative pole is a retrospective detector for C++ declaration boilerplate: it fires on a postfix reference declarator (an & directly following a type name, as in const T& or QString& parameters, which fires even in short signatures), on the JSDoc @constructor tag, and — only when #include plus namespace scaffolding precedes them — on class headers, public:/private: access labels, and namespace tokens. It stays well below those peaks on lookalikes lacking C++ declaration markers: plain C (typedef/struct/malloc/printf/scanf, whose only & uses are prefix address-of or infix bitwise), Rust (pub struct with prefix &self/&mut), C#, Java, #pragma-only lines, other doc tags like @param, prose uses of the same words, and bare .so/path or package-list fragments.
