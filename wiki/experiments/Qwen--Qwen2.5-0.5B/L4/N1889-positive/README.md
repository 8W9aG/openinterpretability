> Detects the letter c/C when it names the C programming language family, retrospectively. The strongest case (8-18) is the lowercase 'c' inside a copyright mark '(c)' right after 'Copyright'/'COPYRIGHT'/'Licensed', as in source-file license headers; uppercase '(C)' is much weaker (2-4) and '(x)', '(b)', a bare '©' or '(c)' with no Copyright word stay near 0. Moderate activity (3-8) comes when ' C' names the language (in C, ANSI C, C++, C#, C/C++, Objective-C, the C:\ drive) or on the token that disambiguates an earlier ' C' as the language (' language'/' programming' after ' C'), and on C-ecosystem tokens ('.h' in #include <...h>, malloc, free, printf). The letter C used non-programmatically (vitamin C, grade C) and other language names (Python, Java, R, D, F#, CUDA) stay near 0.
