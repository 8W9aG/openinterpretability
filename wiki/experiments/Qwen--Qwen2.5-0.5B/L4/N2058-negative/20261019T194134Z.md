## Hypothesis

> Fires on a prefix (unary) operator token that opens an operand where the syntax expects an operand, not an operator, in code or arithmetic: above all a space-preceded unary minus ' -' right after a binary/comparison/logical operator, '=', ':=', ',', 'return' or a keyword ('5 - -3', '3 + -5', '&& -y', 'i == -1', 'foo(a, -1)', 'return -1'), strongest (~3-5.7) when the preceding token is itself an operator.
