**Latest status:** VERIFIED (2026-10-19)

> Fires on a prefix (unary) operator token that opens an operand where the syntax expects an operand, not an operator, in code or arithmetic: above all a space-preceded unary minus ' -' right after a binary/comparison/logical operator, '=', ':=', ',', 'return' or a keyword ('5 - -3', '3 + -5', '&& -y', 'i == -1', 'foo(a, -1)', 'return -1'), strongest (~3-5.7) when the preceding token is itself an operator. Other operand-opening prefixes are weaker (unary ' +' ~2.5, ' ~'/' !' ~1-1.5, a regex-literal '/', an ObjC message ' [' in code), while the same ' -' used as a binary operator after an operand ('x - 1', '5 - 3', '3 - 2' in prose) and literals without a sign stay near zero.
