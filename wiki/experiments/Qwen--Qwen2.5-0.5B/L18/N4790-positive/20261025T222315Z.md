## Hypothesis

> This pole fires retrospectively when the current token completes a conventional, stereotyped multi-token construction: a fixed idiom or collocation (because of, not guilty, golden brown), boilerplate or code idiom (Hello-world closing tag, range(, def-header return, fairy-tale adjunct comma), a canonical memorized proposition (boiling-point Celsius, Where-are-you-going), or punctuation closing a complete clause. Strength scales with stereotypicality (canonical chunks ~0.6-0.8, frame-preserving substitutions ~0.2-0.3), and the same tokens in novel compositional uses (weather-report Celsius measured 0.000, felt guilty 0.000, return the book 0.004, brown fox 0.07, abbreviation dots ~0.05) stay near silent, so the claim beats the token-identity confound (R2 69%).
