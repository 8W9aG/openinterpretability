## Hypothesis

> In code and config text the negative pole fires at the boundary where a filesystem path's value is introduced: on the drive-letter token of an absolute Windows path ('my drive is C', 'Install Dir: C:\Program Files', 'new File("c:\test")'), and on the opening quote, '("' or ':' that starts a file/directory/path value ('File "manage.py"', 'open("config.json")', 'String path = "..."', 'String dir = "..."', 'Docker Root Dir:'). It is near zero when the same syntax carries a non-filesystem value (name/url/host/port/ip/database variables, 'Name:'/'Color:'/'Version:' labels, a numeric literal in the same slot, POSIX paths or URLs in prose), while its output direction pushes a path root - a drive letter, then ':\' - and suppresses ' int', mirroring the studied positive pole, which fires at value slots where an integer is expected.
