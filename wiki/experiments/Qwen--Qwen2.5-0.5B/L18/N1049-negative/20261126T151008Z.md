## Hypothesis

> In code, config and prose, the negative pole fires at the value-slot boundary where a filesystem path is introduced: on the drive-letter token of Windows-absolute paths (C:/, D:/, strongest), and on the opening quote, paren-quote, colon or preposition (=", (", File ", Root Dir:, at, E.g.) that starts a POSIX-absolute (/opt/..., /var/...) or relative slash-path (src/..., reports/..., Assets/...) value. It stays near zero when the same syntax carries a non-path value — numeric literals like "300", version labels, name/host/port/ip/database variables and integer slots — and its output direction pushes path-root tokens (':\', ':\\') while suppressing 'int'.
