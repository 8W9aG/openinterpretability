## Hypothesis

> L23/N1769+ is a retrospective 'Java-family member declaration' unit: in Java, Kotlin, Swift, Dart, Scala and Java-style C# source it peaks on the token that opens a declared member - a field modifier (private, public, static, final), a method or constructor name just before its '(', a ':' or '->' introducing a type, a ',' or '<' inside a capitalised parameter or generic list, or the indentation that begins the next member or statement line - and its write suppresses the built-in type tokens it expects ('String', 'Math'). Activation is primed by the members already written in the window, so the first field of a class body scores 3-6, the second and later members 8-10, and full Java/Kotlin/Swift class bodies reach 8-17; sparse Java-shaped code still fires at 3-6 (a Rust struct/impl, a C# class written with lowercase 'string', a Java method body containing a for loop and println calls, a JavaScript function of arithmetic assignments, the same class written with lowercase types), while Go, C, C++, PHP, Ruby, Python, TypeScript classes and interfaces, plain JavaScript without a Math call, SQL, shell, HTML, JSON, YAML and prose stay at or below about 2.5.
