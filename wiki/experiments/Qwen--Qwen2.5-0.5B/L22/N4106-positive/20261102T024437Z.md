## Hypothesis

> L22/N4106+ is a retrospective detector for specialised nomenclature: it fires on (or on the token immediately after) a domain-specific name string embedded in text written in that domain's register - a code identifier or shell command (chmod, INFORMATION_SCHEMA, cgroupfs, ds.Tables), a clinical/chemical or gene-product term (fluorouracil, capecitabine, erythrodysesthesia, Akt, ERK1/2), or an uncommon proper name (Gagnon, Kankakee). The same sentence with that string swapped for an everyday equivalent in the same slot (cp for chmod, aspirin for fluorouracil, customer_orders for INFORMATION_SCHEMA, Brosnan for Gagnon, Illinois for Kankakee) drops to near zero, and ordinary prose, abstract nouns and function words stay near zero throughout. Concrete part/place nouns in formal descriptive prose (shelf, chimney, rear, door) give a weaker, less reliable response that usually stays below the activity line and is treated as a secondary offshoot, not the main job.
