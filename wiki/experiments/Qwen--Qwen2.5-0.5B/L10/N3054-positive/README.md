# Qwen/Qwen2.5-0.5B · L10/N3054+

[← wiki home](../../../../README.md)

**Latest status:** VERIFIED (2026-10-19)

> Fires on the content tokens of a hand-written literal data value in code, config, connection strings, paths or command lines: the sample or placeholder string a programmer typed in, such as a person's name, password, username, hostname, sheet or folder name, or the words demo/test. It is strongest on the first one or two subword tokens after the opening quote, '=', ':\\' or '-l' that begins the value, and on arbitrary or idiosyncratic values ("Maria", "demo", tecmint, students, C:\\BE). It is weak on conventional system or default values (Windows, Sheet1, Sales, localhost, 127.0.0.1) and near zero on keywords, variable references (null, None, $other, getpass()) and ordinary prose, even when the prose contains the same word.
