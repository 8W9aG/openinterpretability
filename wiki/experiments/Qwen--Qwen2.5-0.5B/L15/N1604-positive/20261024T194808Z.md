## Hypothesis

> L15/N1604+ fires when processing function calls that establish a callback or async continuation point, and stays quiet on straightforward value-returning calls. The activation peaks at the boundary where the call's continuation is defined (e.g., ').' before .success(function(', 'String.class' for AjaxCallback, 'click(function('), or on security-related parameters like password. The firing is retrospective: it reads ahead through the call's arguments to recognize the callback/event handler pattern (AjaxCallback class name, .success() method name, .click() event handler), then fires at the marker where the continuation is registered. Examples driven mostly by surrounding context (http.post string, url parameter) because they show the callback pattern clearly; examples driven mostly by the peak token (click, password) because those tokens themselves signal the callback/event or security context.
