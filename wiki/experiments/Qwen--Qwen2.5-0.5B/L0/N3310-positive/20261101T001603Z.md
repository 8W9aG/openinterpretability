## Hypothesis

> Layer-0 lexical key, not a meaning detector: the pole's strength on a text is the max over its tokens of a fixed per-token-type key, so the peak sits on that token, a long passage is active as soon as one key token appears anywhere in it, about 2% of the vocabulary is above the 0.32 activity threshold, and ordinary prose with no key token stays at or below ~0.2 (20 such sentences measured <=0.17). The interpretable head of the key is amount/degree vocabulary (' handful' 1.45 in a sentence, ' plenty' 0.98, ' plethora' 0.74, ' myriad' 0.77, ' quota' 0.71, ' minority' 0.51, ' majority' 0.49, ' few' 0.39, ' subtly' 1.11, ' passionate' 0.86, ' incapable' 0.69, ' capable' 0.59, ' questionable' 0.64, ' potentially' 0.97), with a semantically unrelated tail of individual tokens and word pieces firing just as hard (' pot' 1.04, ' potato' 0.49, ' mosquito' 0.55, 'caret' 1.14, ' tasty' 1.21, ' dorm' 0.89, 'expire' 0.55, 'epad' inside ' Notepad' 1.00, 'ika' inside ' Troika' 0.63, and scattered code or control identifiers such as 'TODO', 'getArguments' and 'ObjectId' near the threshold). Because the key belongs to the token type and not to the sense, ' handful' fires in 'a handful of them' (1.45) and in 'a handful at bedtime' (1.43), ' potential' fires in 'potential energy' and ' minority' in 'the minority party', while near-synonyms that are different tokens stay silent (' modicum' 0.00, ' dash' 0.02, ' pinch' 0.20, ' numerous' 0.08, ' abundance' 0.21, ' quantity' 0.13, ' many'/' much'/' several'/' number'/' amount' <=0.12, ' meticulous' 0.05, ' esoteric' 0.02); words fire only when the Qwen tokenizer emits a high-key piece for them - the mid-sentence space-prefixed ' handful' fires, a sentence-initial capitalised ' Handful' (tokenised 'Hand'+'ful') does not, and ' Notepad' fires through 'epad' while 'capability' 0.06, 'questionably' 0.05 and 'expires' 0.19 do not. Its negative pole is the mirror contrast: directional '-ward/-orth' tokens (' forward' -3.8, ' onward' -1.5, ' clockwise' -1.0) suppress the unit and so sit at 0 on this pole.
