It stays near zero for the same words in other roles (comitative 'came with a friend', noun-modifying 'the woman with a red hat', passive agent 'written by a famous author') and for non-means prepositions in the same slot ('about', 'for', 'of', 'in', 'at', 'after'). A separate leftover: it also fires strongly on the token ')\n' that closes a legal citation year like '646 (2001)' followed directly by a newline.
