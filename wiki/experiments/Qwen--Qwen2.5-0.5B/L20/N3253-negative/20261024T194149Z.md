## Hypothesis

> This pole fires on tokens that are highly predictable from their left context — conventional collocations ('central' in 'the central bank'), expected function words ('the' after a preposition), number continuations ('9' in '1969'), keyword-licensed slots ('add' after 'def') and subword completions ('ist') — i.e. it marks low-surprisal, informationally redundant tokens. The same token in a less constraining context fires weakly while changing only the following token leaves the peak unchanged, and it prepares no coherent upcoming-token set (Jacobian-lens kurtosis ~3.4 with incoherent promoted fragments), so the mechanism is retrospective.
