> The pole is a retrospective 'committed completion' detector: it peaks on a token when the model already holds a nearly determined completion for what follows, either a sub-word piece whose remaining letters are forced (del|uded, deb|riefing, tele|fonene, re|arg|ues, cumhur|ba|şkanı, proverb|ial - the fragment set is idiosyncratic: del-, deb-, tele-, tra-, comp-, det-, dec-, def-, rel-, rec- peak while des-, dev-, comm-, tes- do not) or an ordinary function word whose next word is nearly forced (a single next token holding about 90%+ probability: 'that comment is beside the |point' peaks on ' the', 'the comment is beside the |point' does not). It stays near zero on complete single-token words (deleted, delighted, debate, telephone) and on function words with an open continuation (the book is on the |table, it is beside the |point at issue).
