> The pole fires when the token just read is a word-internal continuation piece that extends a multi-token word (ret in 'konkret', et in 'opholdet', at in 'sertifikatet', inite in 'indefinite', unct in 'disjunct', iten in 'finiteness', ct in 'dis junct') - i.e. when the model is part-way through assembling a word - and is near-silent when the same string begins a word after a space (' ret') or when the word is a single token (' adjunct'). A weaker second trigger is a Latinate stem in nominal/adjectival use after a determiner (the express / discrete / distinct cases, 'Visual Studio Express'), which does not fire when the same token is the clause's main verb ('We express ...').
