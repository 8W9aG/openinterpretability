3. Channel identifiers

Channel identifiers are allocated by the registrar described in Section 6. Values below 128 are reserved for the standard measurement types defined in this document. Values from 128 to 255 are available for private use, provided that both ends of a link agree on their meaning. A receiver must not assume that a private channel carries any particular unit or scale.

4. Encoding rules

Numeric values are encoded in the smallest representation that can hold them without loss. Integers are encoded as variable-length quantities using the scheme described in Section 4.2. Floating point values are encoded in IEEE 754 binary32 unless the channel definition specifies binary64. Text is encoded in UTF-8 without a byte order mark, and implementations must reject strings containing unpaired surrogates or overlong encodings.

5. Error handling

A receiver that detects an error must not attempt to resynchronise by scanning for the next header within the same buffer; it must discard the remainder of the frame and wait for the next one. This rule exists because resynchronisation has historically caused receivers to interpret payload bytes as headers and to report measurements that were never taken. Implementations that log discarded frames should record the reason for the discard and the offset at which the frame began.

6. Registration

Requests for channel identifiers are submitted to the registrar in writing and are reviewed twice a year. The registrar maintains a public list of assigned identifiers, together with the measurement type, unit and scale associated with each one. Identifiers that have not been observed in traffic for a period of five years may be reclaimed after a notice period of twelve months.

7. Conformance

The key words "MUST", "MUST NOT", "REQUIRED", "SHALL", "SHALL NOT", "SHOULD", "SHOULD NOT", "RECOMMENDED", "NOT RECOMMENDED", "MAY", and "OPTIONAL" in this document are to be interpreted as described in BCP 14 [RFC2119] [RFC8174] when, and only when, they appear in all capitals, as shown here.” (activation 0.384)
