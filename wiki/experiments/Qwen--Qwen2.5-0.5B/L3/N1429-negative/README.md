> The negative pole is a sparse two-token completion detector: it peaks only when the current token completes a memorized fused unit whose first half was the immediately preceding token, either a split word/identifier ('aut'/' ES' -> 'orest'/'Xi', 'Solid' -> 'Works', 'XML' -> 'StreamReader', 'Semi' -> 'Bold', '.find' -> 'DOMNode', 'crypto/' -> 'rsa', ',C' -> 'URLOPT', '(object' -> ' sender') or a fixed pair ('Bernie' -> ' Sanders', 'Silicon' -> ' Valley', '#pragma' -> ' clang', 'the' -> ' top', 'At' -> ' our', ',' -> ' my').
