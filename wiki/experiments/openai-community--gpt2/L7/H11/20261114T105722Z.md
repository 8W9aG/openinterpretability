## Hypothesis

> This head copies the first token of the current line when that line ends: at a '\n' (and, more weakly, at the last word of a sentence, verse line or comma-delimited item) it attends to a line-initial token — the nearest one, or an earlier line's first token — instead of to the text's first token, which is its default sink, and its OV circuit (a near-identity map: a source token's top promoted token is itself) writes that line-initial token into the residual stream at the boundary. The write is large only when the retrieved key is an internal line start, because the text-initial sink's value is close to the head's mean output while a later line start's is not; so it fires at line ends in any text with internal line breaks and stays near its floor in a single unbroken block, where the only line start is its first token.
