## Hypothesis

> This pole is a retrospective detector for the sort-key identifier token immediately completing an ORDER BY clause in SQL-like queries: it peaks on the column name (e.g. ' name'), jointly licensed by the preceding ORDER and BY tokens, which single-token ablation shows drive the peak nearly as much as the peak token itself (0.73/0.83 vs 1.00).
