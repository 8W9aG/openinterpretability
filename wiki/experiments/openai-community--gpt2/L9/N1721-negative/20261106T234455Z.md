## Hypothesis

> N1721- is not a content feature but GPT-2's GELU dip read through this neuron, so it fires on a resting state rather than on a topic: the MLP computes gelu_new(c_fc(x)), the pole strength is max(-gelu_new(pre), 0), and it is hard-capped at the gelu_new global minimum 0.1700408 (pre about -0.75), exactly 0 whenever pre >= 0, with this scan's maximum exactly that constant and all 20 top peaks float32 ties at it (it is active, at or above 0.25 of scale, on about half the scan's 199,964 tokens). Two facts decide a label. (1) A text's first position is always cold: at position 0 the pole reads exactly 0.000 for all 50,256 GPT-2 vocabulary tokens (measured in one batch, maximum 0.000), whatever the token, script or rarity, so a prompt that tokenizes to ONE token - 'cat', ' math', ' location' - is INACTIVE with peak 0.000, as is a whitespace-only prompt. (2) After the first token the pole sits at the cap (0.10-0.17, 0.6-1.0 of scale) on lexical tokens - nouns, verbs, adjectives, names, numbers, subword pieces, code identifiers, non-Latin script - and also on ' is/was/are/were/be/been/have/has/can/will/it/you/I/we/they/that/this/not' and bare letter or digit pieces, while it reads 0 on whitespace and, most of the time, on punctuation and on the commonest space-prefixed phrase-structure words (' the/a/an/of/in/for/with/by/from/as/or/but/and/The/In/A/its/his/their/my/your/than/said'). Hence label a prompt ACTIVE (peak 0.6-1.0 of scale) when it has two or more tokens and any token after the first is a lexical word: 32-token windows of the scan's running text are active 98.9% of the time (1,123 windows), 10-token spans 90.6% (3,458), and 18 of 18 hand-written sentences - and label it INACTIVE (peak exactly 0.000) only when it is a single tokenizer token. Strings of 2-9 closed-class tokens are NOT decidable from text and are not valid hard negatives: ' the of and to a in' and ' the the the' read 0.000, but ' of the' reads 0.100, ' in the of' 0.134, ' is is is is' 0.164 and ' at the' 0.170, because attention copies earlier tokens into the current residual. The pole's output direction prepares no upcoming token (Jacobian lens kurtosis 3.1, an incoherent promoted list, and no correlation with the next token's surprisal, rho +0.01), so it is retrospective.
