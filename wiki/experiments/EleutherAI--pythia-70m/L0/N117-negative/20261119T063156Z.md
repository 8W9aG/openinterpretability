## Hypothesis

> Default-on token-identity unit (GeLU dip): a token goes quiet, and a text goes quiet only when every token after the first does, in two cases. (a) The very frequent glue tokens drive the pre-activation far below the dip: ' the', ' of', ' to', ' a', ' and', ' in', ' is', ' that', ' for', ' with', ' by', ' on', ' was', ' are', ' "', and the punctuation and whitespace '.', ',', ':', ';', '(', ')', '{', '}', '-', '/', '_', '\n'. It stays on for pronouns and possessives (it, he, his, their), ' this', ' at', ' from', ' have', ' been', '!', '?', numbers, and most nouns and adjectives (plan, house, man, new).
