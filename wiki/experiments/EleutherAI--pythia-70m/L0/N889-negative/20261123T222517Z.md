## Hypothesis

> This pole is the GELU floor of layer-0 neuron 889, not a semantic feature: its strength is -gelu(LN(e_token)·w_in), an exact function of the current token id that is identical in every context (measured max difference 0.0 across prefixes), so it pins at its 0.170 ceiling (the GELU minimum) for the fixed set of ~1,680 vocabulary ids whose embedding is anti-aligned past that minimum ('ite', ' Save', ' saved', 'under', 'needs', 'some', 'important', 'various', 'please', 'grievance' - a list with no shared topic, script or part of speech).
