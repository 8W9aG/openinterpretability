## Hypothesis

> This is an L0 unigram-gated GELU-dip pole: it fires maximally on the current token whenever that token's embedding lands the neuron's pre-activation near the GELU minimum (~-0.75), which holds for bare word-fragments like 'of' inside longer or hyphenated words and for mid-frequency whole words such as ' which', ' ->', 'She' and ' Status'. It shuts off on both sides of that tuning curve: ultra-frequent standalone tokens (' of', ' the', ' to', ' and', '.', ',', '-') push the pre-activation far negative so both poles go quiet, and a smaller set of embeddings ('Hello', ' also', 'oo', 'ia') push it positive so only the positive pole fires.
