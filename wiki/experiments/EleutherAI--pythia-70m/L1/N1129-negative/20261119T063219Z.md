## Hypothesis

> The pole is on at almost every token of ordinary prose and code, and it goes quiet on the nouns of a bare software or technical noun-compound keyword string, such as 'Linux kernel module', 'Python package index', 'SQL query optimization' or 'Web server logs', where every token after the first is a whole-word technical noun. A short text is predicted quiet only if it is such a string throughout. Inserting a conjunction ('and'), a preposition such as 'in' or 'for', a determiner ('the'), an auxiliary ('was') or a comma inside the string brings the pole back on at that token, and so do non-technical noun strings that start with a weak word (e.g. 'Water pump repair') and word-piece splits (e.g. 'Un|ix', 'D|ocker').
