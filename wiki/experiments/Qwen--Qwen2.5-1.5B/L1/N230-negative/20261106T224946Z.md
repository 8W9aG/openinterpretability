## Hypothesis

> Layer-1 lexical detector for a small closed set of high-frequency, space-prefixed 'light' modifier words: above all ' still', ' able', ' little', ' how' and ' soon', more weakly ' willing' and ' alive'. It peaks when that word fills a clause-medial modifier/complement slot right after a light function word ('was still', 'be able to', 'a little', 'is how ...', 'as soon as'), is about 4x weaker when the same word follows a content word instead ('the problem still remains' 0.24 vs 'the problem was still there' 1.07), and is near zero on near-synonyms (already, bit, glad, when, early), on capitalized/other token variants, and on the same letters inside a longer word. The word that follows it does not change the response.

- **Activating tokens:** ` still`, ` able`, ` little`, ` how`, ` soon`, ` willing`, ` alive`
- **Mechanism claimed:** retrospective
- **Max activation (scan):** 1.1558
