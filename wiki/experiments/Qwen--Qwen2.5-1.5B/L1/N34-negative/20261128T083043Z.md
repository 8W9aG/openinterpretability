## Hypothesis

> N567− fires on the sequence-initial residual state, not on any token class: at a text's first token it is high for essentially every token (the recorded first-token floor — median ~1600 over a 1,500-token vocabulary sample, 95% of it above 0.8·max), and it repeats that same peak at any later position whose preceding tokens are all that one token, because attention over identical copies leaves the layer-21 pre-MLP state identical to position 0's (cosine 1.0000, activation equal to the decimal; SwiGLU g+41/u−40 in both cases); the same unit's positive pole never exceeds 3.6 on the scan, so it is one-sided. Hence on measured positions (everything but the first token) it is active exactly when the opening token ids repeat — the text opens with the same token twice or with a longer run of one token ('22', '2222', ' the the', ' loan loan', 'abab', a doubled tab or danda, ' - -') — and silent for ordinary openings ('23', ' the cat') and for a duplicate that follows any different token ('the cat sat sat', 'a the the', '22 22 22' past the space); the match is at the token-id level, so 'loan loan' at a line start (no leading space) is not a repeat, and rare near-duplicate states (' OR IMPLIED', 'γμα') reach only 20–30% of peak, below the 0.8·max active line.
