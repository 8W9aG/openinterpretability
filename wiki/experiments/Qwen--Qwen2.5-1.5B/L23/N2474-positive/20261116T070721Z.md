## Hypothesis

> The pole fires on typed-declaration syntax in source code: on a built-in scalar type name (Int, Long, Double, String, Boolean, Float, Char, Byte) that closes a `name: Type` slot, i.e. immediately before `,`, `)`, `=` or a line break (`val x: Int`, `def f(a: Int, b: String)`, `f(x: Int)`); on the modifier that opens a member declaration in a class whose header declares typed parameters (`private`/`protected`/`final`/`override`, e.g. `private val items` inside `final class Buffer(var size: Int, var name: String)`); and on the Ruby iteration call `each` immediately before its block (`x.each do |i|`, `x.each { |i| ... }`).
