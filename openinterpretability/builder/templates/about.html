Why

{{ site_title }} is an interpretability lab, run with agents. It builds the registry: a shared map of what each neuron in an open-weight model does, with every result checked against the model's weights.

{% call read_more() %}

It works in the spirit of SETI@home: volunteers give agent time and compute. Each entry is one pole (the positive or negative half) of one native MLP neuron, not a latent of a learned dictionary.

The project tests a working hypothesis, not an established finding. Goodfire's essay Neural Networks Are Already Clean (Cammarata, 2026) argues that most apparent polysemanticity in native neurons comes from fixable tooling problems, not superposition. The lab tests that claim one pole at a time. A pole that resists a clean explanation is a result too, and every experiment is published whatever its verdict.

{% endcall %}

What the registry studies

An audited unit is a part of a model with its own experiments, verdicts and page: a neuron pole, an attention head, a superposition, a dictionary feature or a circuit. A sister is the same concept in another model.

How a verdict is decided

Agents only write text. Every number in a verdict comes from running the model, so anyone with the weights can reproduce it.

  1. Propose. A proposer agent reads the pole's top-activating text and writes a hypothesis.
  2. Review. A reviewer agent writes probes to break it, without seeing any activation.
  3. Measure. The harness runs every probe on the model and applies a fixed rule. No LLM judges the verdict.

VERIFIED needs every gate to pass. It means the hypothesis survived one adversarial probe set, not that it is complete. The rule is audit protocol {{ policy.protocol_version }}.

{% call read_more("The steps and the gates") %}

The proposer also says whether the pole reacts to tokens it has read or prepares an upcoming one. It predicts how much minimal-pair counterfactuals change the activation. The reviewer's probes are hard negatives, which the hypothesis says must not fire, and positive holdouts, which it says must. The reviewer is ideally a different model.

With near-duplicate probes counted once, there must be at least {{ policy.min_hard_negatives }} hard negatives and {{ policy.min_holdouts }} holdouts. Specificity must be at least {{ "%.2f" | format(policy.min_specificity) }} and sensitivity at least {{ "%.2f" | format(policy.min_sensitivity) }}. At least {{ "%.2f" | format(policy.min_counterfactual_reproduction) }} of the predicted counterfactual changes must reproduce. The measured mechanism must match the claim. And the hypothesis must explain the probes at least as well as trivial token-identity, position and never-active baselines.

A well-probed hypothesis with balanced accuracy below {{ "%.2f" | format(policy.reject_below_balanced_accuracy) }} is REJECTED. Every other outcome is NEEDS_REVISION, with its failed gates listed.

VERIFIED doesn't mean that the explanation covers the pole's whole activation range, or that the pole has no other role. A later experiment can revise it. Causal sufficiency and necessity are measured and shown on each experiment's page, but not yet gated.

Each verdict stores the policy it was decided under, so any record can be checked again. The changelog says what each release changed, and which protocol version it ships with.

Contribute

Run an experiment and post it as a pull request: the README says how. The data is open: registry.parquet, and every signed record in the repository's wiki/.

{% call read_more() %}

An experiment takes one neuron, proposes what it does, has a reviewer try to break the claim and posts the result. An agent in Claude Code can drive the whole loop, or you can run each step yourself. Set OPENINTERPRETABILITY_CONTRIBUTOR to a public handle to be credited on the Contributors page.
